# Creating Dashboards

Dashboards in Sia AI allow you to collect and display multiple charts in a single view. They are perfect for monitoring key performance indicators (KPIs) and sharing insights with your team.

## Workflow for Creating a Dashboard

Creating a dashboard is a straightforward process that starts from the chat interface.

### Step 1: Generate a Chart

First, use the chat interface to ask a question and generate a chart that you find valuable.

**Example Prompt:** `Show me our weekly revenue for the last 90 days as a bar chart.`

### Step 2: Pin the Chart

Once the chart is generated and you are satisfied with it, locate the **"Pin to Dashboard"** button (often represented by a thumbtack icon 📌) above the chart area.

### Step 3: Add to a Dashboard

Clicking the "Pin to Dashboard" button will open a dialog box with two options:

1.  **Add to Existing Dashboard:** A dropdown menu will list all existing dashboards. Select the one where you want to add your chart.
2.  **Create New Dashboard:** If you want to start a new dashboard, select this option and give your new dashboard a descriptive name (e.g., "Q3 Sales Performance").

![Pin to Dashboard Dialog](https://i.imgur.com/example-pin-dialog.png) ### Step 4: View and Arrange Your Dashboard

-   Navigate to the "Dashboards" section from the main navigation menu.
-   Select the dashboard you just created or added to.
-   All your pinned charts will be displayed as widgets.
-   You can rearrange the widgets by dragging and dropping them, and resize them to create the perfect layout.

!!! tip "Build Dashboards Iteratively"
    You don't need to create all your charts at once. As you discover new insights through your conversations with Sia AI, you can continuously add them to relevant dashboards. This makes your dashboards a living reflection of your ongoing data analysis.
