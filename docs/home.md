# The Chat Interface: Asking Questions

The Home Page is your primary gateway to interacting with Sia AI. Its design is centered around a conversational experience, allowing you to ask questions about your data as if you were talking to a data analyst.

## Page Layout and Components

The chat interface is simple and intuitive, consisting of four main areas:

1.  **Chat History (`Left Sidebar`):** All your previous conversations are saved here. You can revisit, rename, or delete past chats.
2.  **Prompt Input Bar (`Bottom`):** This is where you type your questions (prompts) to the AI.
3.  **Response Area (`Center`):** The main content area where Sia AI displays its answers. This can be a data table, a chart, or a text-based answer.
4.  **Interaction Tools (`Above Response`):** After a response is generated, several tools appear:
    * **Change SQL:** View and edit the SQL query generated by the AI.
    * **Change Chart Type:** Switch between different visualizations (e.g., bar chart, line chart, pie chart).
    * **Save to...:** Save the query as a View or add context to the Knowledge Base.
    * **Pin to Dashboard:** Add the current chart to a new or existing dashboard.

## User Interaction Flow

Your workflow on the chat page typically follows these steps:

1.  **Ask an Initial Question:** Start by typing a clear question into the prompt input bar. For example: `What were our total sales last quarter?`
2.  **Review the Response:** Sia AI will process your request and generate a response, usually a chart or a number.
3.  **Ask Follow-up Questions:** You can continue the conversation to refine your analysis. The AI remembers the context of the current chat. For example:
    * `Break that down by product category.`
    * `Now show it as a line chart.`
    * `Compare it to the same quarter last year.`
4.  **Refine or Correct:** If the chart doesn't look right, use the **Change SQL** button to inspect and correct the underlying query.
5.  **Save Your Work:** Once you are satisfied with a chart or query, use the **Pin to Dashboard** or **Save to View** features to preserve your work.

!!! tip "Start Simple, Then Iterate"
    It's often best to start with a broad question and then ask follow-up questions to drill down into the details. This conversational approach is a strength of Sia AI.
